# Journey-of-the-Sorcerer
--------------
Este será el diario de mi viaje aprendiendo a programar de manera seria

Para asegurarme que hago un buen trabajo y que dejo un rastro de migajas que qlaguién pueda seguir algún día ire dejando por aquí cuales han sido mis herramientas y fuentes de estudio.

No se para donde voy... nunca lo se con certeza. Me siento como si flotara en el espacio sin control y sin prisa. Pero lo bueno de la gravedad es que inevitablemente termina llevándote a algún lugar.

Iré dividiendo mis aprendizaje en niveles para poder dedicarle a casa cosa su tiempo y no estar pivotando entre temas, como sé que terminaré haciendo de todas formas.

##Nivel 0: Git me way out  of here.

Tutorial oficial para instalar .NET 10 y crear la primera aplicación.
Guía oficial de la CLI de .NET.
Introducción a GitHub, que toma menos de una hora y cubre repositorios, ramas, commits y pull requests.
Learn Git Branching, únicamente los niveles iniciales.
